# GIF Search

A simple project built as part of **The Odin Project** to practice working with APIs using JavaScript's `fetch()`.

## Features

* Fetch random GIFs from the GIPHY API
* Search GIFs by keyword
* Load a new GIF without refreshing the page
* Basic error handling for invalid searches and failed requests

## Built With

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API
* GIPHY API

## What I Learned

* Making asynchronous requests with `fetch()`
* Handling promises using `.then()` and `.catch()`
* Parsing JSON responses
* Validating API responses using `response.ok`
* Updating the DOM dynamically
* Basic error handling for network and API errors

## Installation

```bash
git clone https://github.com/your-username/gif-search.git
cd gif-search
```

Open `index.html` in your browser or use a local development server.
